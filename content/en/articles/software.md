# What Software to Build Next: My Game-Changer with a Positive Twist (and a Latvian Spark)

So, here I am, sipping kvass on a breezy Riga afternoon, dreaming up my next big move. What software should I build next? Something impactful, fun, and totally me. Let’s dive into this brainstorming sesh, juggling cool ideas, programming languages, and a little Latvian flair - because why not?

![preview](https://raw.githubusercontent.com/vdeksne/portfolio-images-2025/refs/heads/main/app.png)

## My Quest for the Perfect Project

Building software isn’t just about coding - it’s about unleashing my inner digital superheroine. Here’s how I’m narrowing it down:

### Problem-Solving Value

What’s the big bad I want to tackle? Maybe it’s Latvia’s talent exodus or those clunky e-gov portals. I could whip up a platform in Node.js with a Vue front-end to link Latvian freelancers with global gigs. Or how about a blockchain-based app to track local amber trades? If it fixes something real, I’m already winning.

### Feasibility

Two years feels like ages, but I’m no sci-fi genius with unlimited time. I’ll start with something I can handle - like a Python tool for secure data sharing - then level it up. Keeping it realistic means I’ll actually finish without losing my mind.

### Relevance to My Interests

I’m all about AI, blockchain, and cybersecurity - my holy trinity! I could code a Python AI model (TensorFlow, maybe?) to detect phishing scams for Latvian users, or a blockchain app in Solidity to secure local supply chains. Obsessed? Absolutely. Burnout? Not a chance.

### Technical Innovation

Time to show off! I could use Rust for a blazing-fast cybersecurity tool - Latvia’s trade game deserves protection - or dive into Ethereum smart contracts for a blockchain twist. Vue’s my front-end BFF, so a sleek interface is a given. I want to be the one everyone’s buzzing about.

### User-Centric Design

My app’s gotta be so easy my grandma could use it blindfolded. A stunning Vue.js front-end is non-negotiable - think clean lines and smooth vibes. Picture a cybersecurity dashboard for small businesses - simple, pretty, and share-worthy.

### Scalability and Impact

I’m dreaming big! Start with a Node.js + Vue site to monitor local cyber threats, then scale it Baltic-wide. If it makes lives safer and catches investor eyes, I’m golden.

### Local Context

Latvia’s my muse. A Go microservice to secure startup data against EU regs? Or a Vue-powered app to lock down tourist info for Riga’s visitors? Rooting it in my homeland feels right - and it’s a love letter to where I’m from.

### Evaluation Metrics

How do I know I’ve nailed it? I’ll set targets: 1,000 users in year one, 99% security uptime on AWS, or a 20% drop in local cyber incidents. Clear wins keep me on track - and impress the profs.

### Riding the Trends

What’s popping in 2025? AI’s my queen - maybe an AI-driven fraud detector? Blockchain’s still hot; a Vue + Solidity app to trace sustainable Latvian timber could slay. Cybersecurity’s my jam too - a Vue dashboard for real-time threat alerts fits the bill. I’ll make it my own, though.

## Small Start, Big Finish

Two years is my runway, and I’m starting with an MVP. Think a Vue + Python app to flag phishing emails for Latvian SMEs - practical, right? Then I’ll add AI smarts or blockchain layers and pitch it to councils. If it takes off, investors in Riga (or Tallinn) might slide into my DMs.

## Latvia’s Geopolitical Edge

Living between East and West keeps things spicy. Security’s huge with Russia next door, so a C++ cybersecurity tool for small businesses could be a total boss move. Or a blockchain app to keep our data sovereign - geeky with a geopolitical edge.

## My Code, My Vision

So, what’s it gonna be? A Python + Vue AI hub to shield Latvian teens from online scams? A blockchain + Vue platform to secure rural trade? Whatever I choose, it’s gotta shine with positive vibes - empowering, protecting, or innovating. I’ll start coding, tweak as I go, and in two years, I might just have a thesis and a startup pitch.

What’s my heart whispering? I’ll mull it over, sharpen my idea, and turn it into something dazzling. Watch this space - I’m building the future, one line of code at a time!
